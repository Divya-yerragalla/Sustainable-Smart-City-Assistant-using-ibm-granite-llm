SmartCity AI Assistant

AI-powered smart city intelligence platform leveraging IBM Granite LLM, FastAPI, Pinecone vector retrieval, and RAG-based conversational AI workflows for sustainability analytics, KPI forecasting, anomaly detection, semantic search, and automated reporting.

🚀 Features
🤖 Conversational AI assistant powered by IBM Granite LLM
🔍 RAG-based semantic retrieval using vector search
📊 KPI forecasting and sustainability analytics
🚨 AI-driven anomaly detection workflows
📄 Automated smart city reporting and document generation
🌐 FastAPI backend with scalable API architecture
🧠 Context-aware conversational workflows
📈 Interactive dashboards and intelligent urban insights
🛠️ Tech Stack
Category	Technologies
Backend	FastAPI, Python
LLM & AI	IBM Granite LLM, NLP
Retrieval	Pinecone, Vector Search, RAG
Frontend	Streamlit
Data & Analytics	Pandas, NumPy
APIs & Tools	REST APIs, Git, GitHub

⚙️ Key Functionalities
🔹 Conversational AI

Enables users to interact with smart city datasets and sustainability policies using natural language queries.

🔹 RAG-Based Retrieval

Implements vector retrieval workflows to improve contextual information access and semantic search relevance.

🔹 KPI Forecasting

Analyzes sustainability metrics and urban datasets to generate predictive insights and trend analysis.

🔹 Anomaly Detection

Detects unusual patterns across smart city operational metrics and environmental indicators.

🔹 Automated Reporting

Generates intelligent summaries and sustainability reports for decision-support workflows.
